Preparando datos locales.

Configura la URL y la clave, y prueba la conexión.

Configuración inicial de Apps Script
  1. Abre script.google.com y crea un proyecto nuevo.
  2. Copia el contenido de APPS_SCRIPT/Code.gs incluido con HomeTasks.
  3. Sustituye CAMBIA_ESTA_CLAVE por una clave larga. Usa exactamente la misma clave en HomeTasks.
  4. Implementa el script como Aplicación web, ejecutándolo como tú y permitiendo acceso a Cualquiera.
  5. Copia la URL terminada en /exec, pégala arriba y pulsa Probar conexión.
